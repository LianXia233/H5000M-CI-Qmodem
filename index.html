  • 已安装本固件用户：推荐直接使用后台 系统 → 在线升级，内置设备唯一锚点自动匹配对应 Release，保留配置直升。

DEEP OPTIMIZATION

CPE 专属硬件套件与底层加速能力

集成模组调试、阶梯温控风扇、双模秒切与企业级 SD-WAN 跨域组网。

5G 模组通用管理

基于 QModem ubus 接口，支持固件版本、频段锁定、RSRP/RSRQ/SINR 信号指标、基站小区信息、APN 配置与在线 AT 指令交互台。

双温感智能风扇温控

实时轮询 CPU 核心与 5G 模组温度，依据动态温控曲线实现多阶 PWM 线性/阶梯变速，兼顾静音与高负载散热。

网络模式毫秒切换

自由切换「纯 5G 蜂窝」「纯 WAN 有线」与「双线负载均衡 / 主备热备」，深度联动 mwan3 探针实现断网毫秒级无感切流。

固件在线直升 (OTA)

固件出厂烙印设备唯一特征锚点，运行时精准命中对应 Release，默认启用保留配置升级（keep_config）并内置国内高速通道。

硬件加解密与轻量 NAS

开启 kmod-cryptodev 与 kmod-tls 卸载 CPU 加解密负荷；集成 NVMe、BTRFS 与 Samba4，轻松化身局域网共享盘。

跨地域异地安全组网

内置 Tailscale、EasyTier 等现代化 SD-WAN 虚拟组网协议，无需公网 IP 即可实现远程穿透与内网资产访问。

GITHUB ACTIONS

自动化云编译流程与自定义构建指引

无需在本地搭建复杂的 Linux 交叉编译环境，完全依托 GitHub Actions 云端编排。

1
Fork 个人仓库
点击仓库右上角 Fork 按钮，将项目克隆到你的个人 GitHub 账号下。
2
启用 Actions 权限
进入 Fork 后的仓库，在 Actions 选项卡中点击启用工作流执行权限。
3
触发 WRT-BUILD
选择机型模板（如 H5000M-qmodem-next），按需填写后台 IP 或 Wi-Fi 参数。
4
发布与产物下载
构建完成后自动在 Releases 生成专属固件产物，支持在线 OTA 自动检查。

云端流水线职责一览

工作流名称 触发机制 核心职能
WRT-BUILD 手动 workflow_dispatch 自定义按需编译，自动匹配分支（X86 固定使用 immortalwrt/master）；支持 TEST=true 语法检查
MTK-AUTO 每日定时 / 手动 全自动并行构建 H5000M 与 AP3000M 的三版本固件（QModem Next / QModem / Modem Pro）
OWRT-ALL 每日定时 / 手动 全自动构建通用 x86_64 平台的双版本固件（含 EFI / Legacy / ISO / VMDK）
Auto-Clean 每日 05:00 (CST) / 手动 回收超过 30 天的编译日志；旧版本 Releases 在新版本发布成功后再自动清理
