  • 已安装本固件用户：推荐直接使用后台 系统 → 在线升级，固件内置设备唯一锚点，会自动检索匹配对应 Release，保留配置安全直升。

Deep Optimization

CPE 专属硬件套件与底层加速能力

集成模组调试、阶梯温控风扇、双模秒切与企业级 SD-WAN 跨域组网

5G 模组通用管理 (`luci-app-qmodem-generic`)

基于 QModem 的 ubus 接口开发，全面支持运行全景实时监控（固件版本、频段锁定、RSRP/RSRQ/SINR 信号指标、基站小区信息与 IMEI/IMSI）。支持快速 APN 配置与在线 AT 指令交互台。

双温感智能风扇温控 (`luci-app-h5000m-fancontrol`)

实时轮询 CPU 核心与 5G 通信模组的工作温度，依据动态温控曲线实现多阶 PWM 线性/阶梯变速。在低负载静音防噪音与极端千兆吞吐散热之间取得完美平衡。

网络模式毫秒切换 (`luci-app-h5000m-netmode`)

自由平滑切换“纯 5G 蜂窝”、“纯 WAN 有线”与“双线负载均衡 / 主备热备”。深度联动 mwan3 探针实时探测连通性，主链路断网时毫秒级无感转移流量。

固件在线直升 (`luci-app-online-upgrade`)

固件出厂烙印设备唯一特征锚点（{机型}-{前端类型}），运行时精准命中 GitHub 对应 Release，杜绝型号错刷；默认启用配置保留升级（keep_config），内置国内高速下载通道。

硬件加解密加速与轻量私有 NAS

底层开启 kmod-cryptodev 与 kmod-tls，卸载加解密运算 CPU 负荷；集成 NVMe 协议支持、BTRFS 现代文件系统与 Samba4，轻松化身高速局域网共享盘。

跨地域异地安全组网 (SD-WAN)

内置 Tailscale、EasyTier 等现代化 SD-WAN 虚拟组网协议，无需公网 IP 即可实现远程穿透、多设备内网打通与出差访问家庭内部网络资产。

GitHub Actions

自动化云编译流程与自定义构建指引

无需在本地搭建任何复杂的 Linux 交叉编译环境，完全依托 GitHub Actions 云端编排

1
Fork 个人仓库
点击仓库右上角 Fork 按钮，将项目克隆到你的个人 GitHub 账号下。
2
启用 Actions 权限
进入 Fork 后的仓库，在 Actions 选项卡中点击启用工作流执行权限。
3
触发 WRT-BUILD
选择机型模板（如 H5000M-qmodem-next），按需填写后台默认 IP 或 Wi-Fi 参数。
4
发布与产物下载
构建完成后自动在 Releases 生成专属固件产物，同时支持在线 OTA 自动检查。

云端流水线职责一览

工作流名称 触发机制 核心职能
WRT-BUILD 手动 workflow_dispatch 自定义按需编译。可自由切换机型与版本；分支自动匹配，X86 固定使用 immortalwrt/master，无需手填；TEST=true 仅语法检查，TEST=false 实质编译
MTK-AUTO 每日定时 / 手动 全自动拉取源码，并行构建发布 H5000M 与 AP3000M 的三版本固件（QModem Next / QModem / Modem Pro，Modem Pro 基于 VIKINGYFY owrt）
OWRT-ALL 每日定时 / 手动 全自动构建发布通用 x86_64 平台的双版本固件（含 EFI / Legacy / ISO / VMDK）
Auto-Clean 每日 05:00 (CST) 定期回收历史过期制品与超过 30 天的 Runs 编译日志，保障仓库整洁
